# 日志语法

## 行格式

```
S<1-6>|<段名>|<动作>|<事件码>|k1=v1|k2=v2…
D|S<n>|…          调试通道（默认静默，S6_TRACE=1 或 /data/local/tmp/s6.trace 才输出）
```

- 段名固定：`自检 / 标定 / 定位 / 回收 / 落位 / 装载`
- 事件码：`E<段><3位>`，段内自增；侧信道用 `F<段><3位>`
- 每行必带 `ok=0/1`

## 主要事件码

| 事件码 | 含义 |
|---|---|
| `E1012` | 起点（含 pid / uptime / nofix） |
| `E2011` | 标定候选与票数 |
| `E3012` | 凭据命中（含 site 低 21 位） |
| `E3031` | 凭据未命中（早停） |
| `E4001` | 布种开始（padding） |
| `E4010` | 抓取失败（recs 数） |
| `E4025` | 布种结果（hit / foreign / free_seen） |
| `E4048` | 布种耗时 `el=`（毫秒） |
| `E5003` | 替换凭据落位 |
| `E5131` | 替身页落位（地址 / selinux / rc_page） |
| `E6001` | 装载推进（stage / target / mode） |
| `E6080` | **全链成功** |
| `E6081` | 阶段收束 |
| `E6120` | 保活挂起（mark） |
| `E6121` | 保活结束（信号） |
| `E6122` | 回收循环停止 |

## 判定规则

- **成功**：出现 `E6080 … ok=1`，且 `/proc/modules` 含 `kernelsu`
- 成功之后的 `E4010/E4047 ok=0` 属于"最后一拍"收尾，不代表失败
- `E6120` + `E6122` 同时出现 = 已停止内核写并进入零 CPU 保活
